# CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GitHub Actions automation that validates pull requests and deploys the Modal app from `master`.

**Architecture:** A single GitHub Actions workflow will install the package, run lint/format/test checks, and gate a Modal deploy job behind successful checks on `master` pushes. A pytest contract test will parse the workflow and verify the important triggers, commands, secrets, and deploy condition.

**Tech Stack:** Python 3.11, pytest, ruff, GitHub Actions, Modal CLI.

### Task 2: Add GitHub Actions CI/CD Workflow

**Files:**
- Create: `.github/workflows/ci-cd.yml`

- [ ] **Step 1: Create workflow**

```yaml
name: CI/CD

"on":
  pull_request:
    branches:
      - master
  push:
    branches:
      - master

jobs:
  validate:
    name: Lint, format, and test
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.11"
          cache: pip

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          python -m pip install -e ".[dev]"

      - name: Ruff lint
        run: |
          python -m ruff check .

      - name: Ruff format check
        run: |
          python -m ruff format --check .

      - name: Pytest
        run: |
          python -m pytest

  deploy-modal:
    name: Deploy Modal
    needs: validate
    runs-on: ubuntu-latest
    if: github.event_name == 'push' && github.ref == 'refs/heads/master'
    env:
      MODAL_TOKEN_ID: ${{ secrets.MODAL_TOKEN_ID }}
      MODAL_TOKEN_SECRET: ${{ secrets.MODAL_TOKEN_SECRET }}

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.11"
          cache: pip

      - name: Install package
        run: |
          python -m pip install --upgrade pip
          python -m pip install -e .

      - name: Deploy Modal app
        run: |
          modal deploy src/aej_dlt/modal_sync_bigquery.py
```
